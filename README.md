 # Ejercicios de Programación Orientada a Objetos en Python

Este repositorio contiene ejercicios desarrollados en Python para practicar Programación Orientada a Objetos (POO).

## Ejercicios

### 1. Gestión de una Biblioteca
Se crea una clase **Libro** con atributos:
- Título
- Autor
- Número de páginas

**Métodos:**
- Mostrar información del libro.
- Actualizar el número de páginas.

### 2. Registro de Estudiantes
Se implementa una clase **Estudiante** con:
- Nombre
- Edad
- Calificación

**Método:**
- Verificar si el estudiante aprobó o reprobó.

### 3. Sistema de Inventario
Se crea una clase **Producto** con:
- Nombre
- Precio
- Stock

**Métodos:**
- Verificar disponibilidad.
- Vender producto.
- Reabastecer inventario.

### 4. Simulador de Vehículo
Se implementa una clase **Vehiculo** con:
- Marca
- Modelo
- Velocidad máxima
- Velocidad actual

**Métodos:**
- Acelerar.
- Frenar.
- Verificar límite de velocidad.
